# SkepiFB

FastBuilder / bridging practice plugin for Paper 1.21.8.

## Features

- FastBuilder practice
- Multiple arenas
- Personal bests and leaderboards
- Replays
- Coins and XP
- Cosmetics
- Custom menus and shops
- Practice mode

## Requirements

- Paper 1.21.8
- Java 21
- WorldEdit 7.2.16+

Optional:
- LuckPerms
- Citizens

## Installation

1. Download the latest release.
2. Put `SkepiFB.jar` into your `plugins` folder.
3. Install WorldEdit.
4. Start the server.
5. Configure the plugin in `plugins/SkepiFB/`.

For full configuration and command information, see
MANUAL.md

## Commands

`/fb help` — Show commands  
`/fb list` — List arenas  
`/fb join <arena>` — Join an arena  
`/fb leave` — Leave an arena  
`/fb reload` — Reload configuration
