# SkepiFB

FastBuilder / bridging practice plugin for Paper 1.21.8.

## Features

- FastBuilder practice
- Multiple arenas
- Straight and diagonal / inclined modes
- Personal bests and leaderboards
- Graphical leaderboard menu
- Replays with position, CPS, ping, and jump-tick information
- Replay favorites, personal-best, last-attempt, sorting, and permission tiers
- Replay holograms and configurable replay actions
- Player spectating
- Practice mode with checkpoints
- Per-mode practice templates
- Per-mode spawn templates
- Coins and XP
- Cosmetics
- Custom menus and shops
- Configurable permissions
- Automatic mode switcher entries
- Player stats GUI
- Island NPC mode switcher
- Periodic chat messages
- Suspicious-time alerts
- Configuration migration and recovery

## Requirements

- Paper 1.21.8
- Java 21
- WorldEdit 7.2.16+

Optional:
- LuckPerms
- Citizens

## Installation

1. Download the latest release.
2. Put `SkepiFB.jar` into your `plugins` folder.
3. Install WorldEdit.
4. Start the server.
5. Configure the plugin in `plugins/SkepiFB/`.

For full configuration and command information, see
MANUAL.md

## Commands

`/fb help` — Show commands  
`/fb list` — List arenas  
`/fb join <arena>` — Join an arena  
`/fb leave` — Leave an arena  
`/fb reload` — Reload configuration  
`/stats [player]` — View FastBuilder stats  
`/spectate <player|exit>` — Spectate a player or exit spectator mode  
`/spec <player|exit>` — Spectate a player or exit spectator mode  
`/lb [mode]` — Open the leaderboard menu  
`/leaderboard [mode]` — Open the leaderboard menu
